## 🛠️ Troubleshooting

Most people get DOOM running without any problems, but here are solutions to common issues:

### The File Doesn't Open

- Make sure your ebook reader supports EPUB 3 format. Some older readers only support EPUB 2.
- Try a different reader. If Apple Books doesn't work, try Google Play Books or Microsoft Edge.

### The Game Runs Slowly

- Close other programs to free up memory.
- Try a smaller window size if your reader allows resizing.

### No Sound

- Check that your device volume is turned up.
- Some ebook readers mute audio by default. Look for a sound icon in the reader's toolbar.

### The Screen Is Too Small

- Use a tablet or desktop computer for the best experience.
- Try rotating your device to landscape mode.

## 📚 More About the Project

doom_epub uses WebAssembly technology to run the original DOOM engine inside the ebook's pages. The entire game—code, graphics, sounds, and levels—is packed into one self-contained file. It's a fixed-layout EPUB, meaning the game appears exactly as designed on every device.
